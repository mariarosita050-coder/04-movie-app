# 🎬 Movie App

A responsive movie application built with HTML, CSS, JavaScript, and the TMDB API.

## Features

- Display popular movies
- Search movies
- Show movie posters
- Show movie ratings
- Show movie release dates
- Show movie overview
- Show detailed movie information
- Show movie genres and runtime
- Loading state
- Error handling
- No results message
- Search using Enter key
- Clear search
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- TMDB API

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the project dependencies with npm install.
4. Create a .env file in the project root.
5. Add your TMDB access token to VITE_TMDB_ACCESS_TOKEN in the .env file.
6. Run the project with npm run dev.
7. Open the local URL provided by Vite in your browser.
